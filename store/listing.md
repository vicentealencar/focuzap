**Summary** (from the manifest `description`, max 132 chars)

```
WhatsApp Web without the distractions: no chat list, no unread badges, no notifications. Search, talk, leave.
```

**Description**

```
You open WhatsApp Web to send one message. Then you see 14 unread chats, three groups with red badges and a Status ring, and twenty minutes go by.

Focuzap turns WhatsApp Web into a search box. Type the name of the person you need, open that chat, talk, and close it. The rest of your inbox stays out of sight until you look for it.

WHAT IT DOES
• No chat list: your conversations only appear while you search, and only the ones that match.
• Message any number: type a phone number with its country code and click "Open chat with +…", even if it isn't in your contacts.
• No badges: hides the filter chips (All / Unread / Groups), the Status, Channels and Communities rail, and their counters.
• Clean tab: "(3) WhatsApp" becomes "WhatsApp" and the favicon stays still, so a background tab can't call you back.
• Quiet: blocks WhatsApp Web's desktop notifications and interface sounds. Voice notes and videos still play.
• Search clears itself once you open a chat.
• Pausing is temporary on purpose: pause for 5 or 15 minutes from the toolbar button when you need the full WhatsApp, and focus mode comes back on its own.

KEYBOARD
• Ctrl+K (Cmd+K on Mac): jump to search
• ↓ then Enter: open a search result
• Esc: close the current chat

PRIVATE BY DESIGN
Focuzap collects nothing. No analytics, no servers, no network requests. It doesn't read or store your messages. It only changes how WhatsApp Web looks in your own browser, and the one thing it saves is when your pause ends.

OPEN SOURCE
Free and MIT-licensed. Read the code, report issues or contribute at https://github.com/vicentealencar/focuzap

Focuzap is an independent project and is not affiliated with, endorsed by, or sponsored by WhatsApp or Meta.
```

## Privacy practices tab

**Single purpose**

```
Focuzap makes WhatsApp Web less distracting. It hides the chat list (shown only while searching), unread badges and counters, and blocks WhatsApp Web's notifications and interface sounds, with a temporary pause.
```

**Permission justification: storage**

```
Stores one timestamp (when a user-started pause ends) so focus mode turns back on automatically, including across tabs and browser restarts. Nothing else is stored.
```

**Host permission justification** (content scripts on https://web.whatsapp.com/*)

```
Focuzap's only function is to change WhatsApp Web's interface: it hides the chat list, badges and navigation rail, and silences notifications and interface sounds on that site. It runs on no other site.
```

**Remote code:** No, I am not using remote code.

**Data usage:** tick nothing. Focuzap does not collect any of the listed data types.
